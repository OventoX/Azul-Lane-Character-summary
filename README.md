# アズールレーン 艦船まとめ表（Azul-Lane-Character-summary）

『アズールレーン』の艦船（キャラクター）データをまとめた個人用の静的Webデータベースです。

## 収録状況（第1弾：UR / 計画艦DR）

- **総収録数**: **47 隻**
- **総収録画像数**: **144 件**（通常立ち絵・着せ替え・ケッコン衣装のみ、装備品アイコン等は除外）
- **レアリティ別内訳**:
  - **UR**: **47 隻**（通常 UR: **32 隻** / 計画艦 DR: **15 隻**）
  - **SSR / SR / R / N（計画艦PR含む）**: **0 隻**（第2弾以降で段階的に収録予定）

### 未収録分について
- **改造によって SSR から UR へ昇格する艦船（6隻）**: サンディエゴ、ウォースパイト、夕立、エルドリッジ、エセックス、ベルファストは素レアリティが SSR のため、本第1弾（素 UR＋計画艦 DR）には未収録です（SSR 収録時に改造形態として同一レコード内に収録予定）。
- **SSR 以下の通常艦・計画艦PR・META・コラボ艦**: 第1弾の対象外のため未収録です。

## 主な機能（v1）

- **艦船一覧（カード表示）**: サムネイル・艦名（日/英）・レアリティ（UR/DR）・艦種・陣営表示
- **検索・フィルター・ソート**: 艦名/艦級検索、レアリティ・艦種・陣営・お気に入りフィルター、図鑑No./ID・レアリティ・名前ソート
- **タグフィルター（5系統・AND条件）**: 雰囲気・性格／見た目モチーフ／髪／着せ替えの種類／その他（コラボ艦・着せ替え多数・Live2D着せ替えあり）のタグチップで複数AND絞り込み・一括解除が可能（全47隻にタグ付与済み）
- **詳細モーダル**: 基本情報（ID・英語名・艦級・CV・絵師・入手方法）、タグ一覧、スキル一覧、出典リンク、着せ替え画像ギャラリー（タップで拡大表示・ピンチズーム・前後ナビゲーション対応）
- **お気に入り保存**: `localStorage` による永続化
- **オフライン対応**: Service Worker（キャッシュ名 `azurlane-matome-v1`、自サイトファイルは Network-first）

## ディレクトリ構成

```text
.
├── index.html          # app/ への転送ページ
├── README.md
├── app/
│   ├── index.html      # アプリ本体
│   ├── style.css       # 海軍風テーマスタイル
│   ├── app.js          # UI・検索・モーダル・お気に入り・SW登録
│   ├── data.js         # 艦船データ（SHIPS_DATA）
│   ├── sw.js           # Service Worker (azurlane-matome-v1)
│   └── manifest.json   # PWA マニフェスト
└── tools/
    ├── build_data.py   # 出典ページからのデータ構築スクリプト
    └── verify_all.js   # データ整合性・必須項目チェック
```

## データ検証方法

```bash
node tools/verify_all.js
```
